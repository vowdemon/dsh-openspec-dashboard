# Design

## Context

参见 proposal.md 与两份增量规格。`Dashboard` 自己持有顶部视图、变更模式和单个搜索词；切换按钮主动清空搜索。`ChangeRow` 与 `SpecRow` 持有展开、子视图和未完成筛选等局部状态，但顶部视图用条件渲染切换整棵列表，隐藏的一侧会卸载；仅分组折叠由 Dashboard 保存。`.osd` 是滚动容器，尚未按视图保留滚动位置。现有 `keepMounted: true` 是右侧栏标签的保活设置，不能阻止看板内部子树卸载。

插件的 `icon.svg` 目前只作为包元数据。已安装 DSH 的右侧栏从 `sidebar.right.pane.tab.title` 插槽渲染标签标题（未注册时回退为纯文字），添加标签页引导的图标来自 tab type 的 `guide[].icon` 组件；当前两者都未提供，不能指望元数据 SVG 自动显示在标签上。

## Goals / Non-Goals

**Goals:**
- 将浏览选择与后台读取数据、写入请求和监听健康分离，内部视图切换时恢复轻量状态。
- 在同一看板生命周期内按 `(sessionId, cwd)` 保存各顶部视图和条目的选择，防止同路径跨会话串用。
- 让包图标、标签标题和添加入口共享一致的文档／任务意象，16px 和明暗主题均可辨认。

**Non-Goals:**
- 不承诺浏览器刷新、插件卸载或应用重启后保留浏览状态；不修改 DSH 右侧栏框架或 Host 接口。
- 不缓存旧任务数据或延续未完成写入、错误反馈、监听状态；不改变任务文件、筛选语义或权限防护。

## Decisions

1. **由 Dashboard 持有受控的浏览状态。** 每个 `(sessionId, cwd)` 拥有一份轻量快照：顶部视图、变更模式、各顶部视图的搜索词、每个变更（以目录路径为身份）的展开／文件或任务子视图／仅未完成状态与分组折叠选择，以及每个规格（以规格名为身份）的展开状态。条目组件只通过 props 和回调展示／修改对应状态，避免条件渲染卸载后重新初始化；未访问条目保持当前默认值。读取到新 Board 时保留仍在数据中的身份并清理已消失身份，不能用数组下标复用条目状态。替代方式是把隐藏列表继续挂载并用 CSS 隐藏，但大型看板会同时构造两份 DOM、保留大量不可见行；轻量快照更适合既有大列表目标。
2. **滚动状态分模式保存，在布局更新后恢复。** `.osd` 的滚动位置以「变更:活动／归档／全部」及「规格」分别记录；离开视图前从当前容器采样，滚动事件持续记录用户操作。在新视图或过滤结果完成布局后恢复位置，并按当前 `scrollHeight - clientHeight` 限幅；不在普通状态更新时反复写入 `scrollTop` 以免与用户滚动竞争。考虑 React layout effect 或等效提交后机制；必要时扩展 `ReactAPI` 类型与测试桩。仅存数值，不保留 DOM 或多份数据结果。替代方式是单独保留 DOM 的 `scrollTop`，但内部列表尺寸变化时浏览器会自动裁剪位置，无法分视图恢复。
3. **会话隔离且只存浏览选择。** 当前 Dashboard 实例在切换 sessionId/cwd 时选择或新建相应快照；返回旧会话时若实例仍存活则恢复。异步加载和 watch 回调继续按当前会话／工作区做原有的身份保护；可见的列表始终来自当前 Board，任务写入进行态、反馈与监听健康不能作为浏览快照共享。如果内存中的会话快照随组件卸载而丢失，允许恢复默认状态，符合不做持久化的范围。
4. **两种尺寸对应一个图标意象，分别接入宿主。** 重画插件根目录 `icon.svg` 为清晰的「OpenSpec 文档＋任务勾选」符号；客户端以内联、主题友好的 React SVG 组件画同一意象的紧凑版，供 `sidebar.right.pane.tab.title` 的标题组件及 tab type `guide[].icon` 使用。标题继续取宿主 tab 的可访问文字，SVG 标为装饰以免重复播报；避免把元数据文件 URL 当成客户端可加载资源或引入新的图标依赖。按 DSH 的 title slot / guide icon 实际签名补充 `ClientContext` 类型，并用注册测试和右侧栏实际场景核验。

## Risks / Trade-offs

- [大量被访问条目的浏览快照增加内存] → 只存布尔值、短字符串与滚动数值，后台刷新时清理已消失的条目，不复制 Board、DOM 或文件内容。
- [搜索、模式切换和刷新导致滚动目标缩短或恢复时机不稳定] → 切换前采样、布局后限幅恢复并避免对用户正在滚动的列表重复写入；覆盖缩短列表与快速往返的测试。
- [状态按会话隔离时任务回调写入错误会话] → 现有请求及结果的 session/cwd 防护继续生效，浏览快照仅存显示选择。
- [插件元数据 SVG 与客户端紧凑图标的形状不一致] → 使用同一轮廓／勾选构图和视觉测试对照；用 `currentColor` 或等效主题颜色保证标题图标可见。

## Migration Plan

不迁移持久化数据。更新客户端包与插件图标后按项目现有方式重新加载插件；回滚该插件版本即可恢复旧行为。完整验证包含模型／渲染／插槽测试和在真实右侧栏中切换顶部视图及检查图标；单独构建本仓库的 `dist` 不视为已更新正在运行的 DSH GUI。
